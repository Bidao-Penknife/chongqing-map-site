================================================
 从测绘重庆到数字重庆 —— 网站部署说明
================================================

【这是什么】
一个重庆地图图层展示网页（纯静态网站），打开就能用，
不需要数据库、不需要后端服务器。

【文件结构】
  site/
    index.html        网站主页面（双击即可本地预览）
    leaflet/          地图库文件（已内置，不需要联网下载）
    README.txt        本说明文件


【第一步：先本地看看效果】
双击 index.html，用浏览器打开，就能看到完整网页。
确认没问题后再进行下面的发布。


【第二步：正式发布（三种方式任选其一）】

--------------------------------------------------
方式一：Gitee Pages（推荐，免费，国内访问快）
--------------------------------------------------
1. 打开 https://gitee.com 注册账号（手机号即可）。

2. 完成实名认证：
   右上角头像 -> 设置 -> 实名认证，上传身份证。
   审核约 1-2 个工作日，免费版必须实名才能用 Pages。

3. 新建仓库：
   点右上角「+」->「新建仓库」。
   - 仓库名称：填英文，例如 chongqing-map
   - 勾选「公开」
   - 其他保持默认，点「创建」。

4. 上传文件：
   进入仓库，点「上传文件」，把 site 文件夹里的
   index.html 和 leaflet 文件夹 一起拖进去。
   注意：index.html 必须放在仓库根目录（第一层，
   不要套一层多余文件夹）。

5. 点「提交」。

6. 开启 Pages：
   仓库页顶部菜单点「服务」->「Gitee Pages」。
   点「启动」，稍等几秒，系统生成网址：
       https://你的用户名.gitee.io/chongqing-map/

7. 打开这个网址即可访问。
   以后改了文件，重新上传后回到这里点「更新」即可。


--------------------------------------------------
方式二：腾讯云 COS / 阿里云 OSS（对象存储）
--------------------------------------------------
1. 注册对应云账号并实名认证。
2. 创建存储桶（Bucket），权限设为「公有读」。
3. 开启「静态网站托管」，默认首页填 index.html。
4. 上传 index.html 和 leaflet 文件夹。
5. 用系统给出的默认域名访问。

   注意：若直接用对象存储的默认域名打开 index.html 时
   变成了「下载」而不是显示网页，说明该云厂商默认给 HTML
   加了下载属性，需要改用「静态网站托管」的访问地址，
   或改用方式一 / 方式三。


--------------------------------------------------
方式三：自己的服务器 / Nginx / 虚拟主机
--------------------------------------------------
把 site 文件夹里的全部内容（index.html + leaflet 文件夹）
上传到网站根目录即可，无需额外配置。
   - Linux + Nginx 一般放在 /var/www/html/
   - 宝塔面板：新建站点后，把文件放到站点根目录


【常见问题】

Q：打开网页后主地图空白或加载很慢？
A：主底图是天地图（国内源），正常应该很快。
   如果整个页面都白屏，先确认 index.html 和 leaflet 文件夹
   都上传了，且 leaflet 里的两个文件没丢。

Q：卫星影像、Esri 影像打不开？
A：这两个图层用的是国外服务器（NASA / Esri），
   国内可能慢或打不开，属于正常现象，不影响主地图使用。

Q：Gitee Pages 网址打不开 / 404？
A：确认 ① 仓库是「公开」；② index.html 在仓库根目录
   （不是多套了一层文件夹）；③ 已在「服务」里点过「启动」。

Q：需要备案吗？
A：用 Gitee Pages 自带的 gitee.io 域名不需要备案。
   只有绑定你自己的域名时才需要备案。
